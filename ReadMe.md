# Tag Checker

Tag checker for validating tags in HTML.

## Tech Stack

**Programming language:** TypeScript

**Test runner:** Jest

## Installation

- Clone the project

```bash
  git clone https://github.com/olesiaMartushkanova/tag-checker.git
```

## Run Locally

Go to the project directory

```bash
  cd yourLocalDirectory/tag-checker
```

Install dependencies

```bash
  yarn
```

Run tag checker programm

```bash
  yarn programm
```

### Add own input to tag checker

Go to

```bash
  cd tag-checker/scripts/runTagChecker.ts
```

Add own input when calling `tagChecker(yourInputHere);` function

## Running Tests

To run tests, run the following command

```bash
  yarn test
```
